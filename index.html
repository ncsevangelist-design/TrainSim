大井町線 運転台

OIMACHI → MIZONOKUCHI　12.4 km

  • マスコン: 力行 P1〜P4、常用ブレーキ B1〜B7。↑↓ または WS で1段ずつ、Space で中立
  • 前後切替: F 前 / V 切 / B 後(停止中のみ)。行き過ぎたら「後」でバックして戻る
  • 種別: T で 各駅停車 / 急行(停車中のみ)。R で最初から
  • CS-ATC の制限速度は運転台のATC表示に出ます。超えると自動でブレーキがかかります
  • ドラッグで見回し、マスコンや各スイッチはクリックまたはドラッグで操作できます
  • VR(Quest): 右スティックを手前で力行・奥でブレーキ / A 前 / B 後 / 左X 種別 / 左Y 最初から / 左スティックで目線の高さ。コントローラーのレイでレバーをつかんでも操作できます

速度段階・加減速度は実車を参考にした簡易モデルです。停止許容は ±3 m(やさしい)から ±0.5 m まで選べ、速度パネルに「ブレーキ目安」が出ます。駅間距離は東急電鉄の公開データ、二子新地・高津は大井町線の駅間表に無いため省略しています。

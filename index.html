大井町線 運転台

OIMACHI → MIZONOKUCHI　12.4 km

  • マスコン: 力行 P1〜P4、常用ブレーキ B1〜B7。↑↓ または WS で1段ずつ、Space で中立
  • 前後切替: F 前 / V 切 / B 後(停止中のみ)。行き過ぎたら「後」でバックして戻る
  • 種別: T で 各駅停車 / 急行(停車中のみ)。R で最初から
  • CS-ATC の制限速度は運転台のATC表示に出ます。超えると自動でブレーキがかかります
  • 方向: D または画面下の「方向」で 大井町→溝の口(下り)/ 溝の口→大井町(上り)を切替(発車前のみ)。上り終点の大井町は頭端ホームで、2番線から転線して1番線に入ります
  • 対向線を6020系(7両、全駅停車)が約5分間隔で走ります。上野毛の追い越し線は上り側のみで、上りの急行がホーム外側のそれを通ります。大井町の転線はダブルクロスです。大岡山は地下駅、自由が丘の上には東横線の高架があります
  • ドラッグで見回せます。マスコンは運転席の真正面で、上下にドラッグすると動きます(下へ=手前に引く=力行、上へ=奥へ押す=ブレーキ)。スイッチはクリックで操作できます
  • VR(Quest): 右スティックを手前で力行・奥でブレーキ / A 前 / B 後 / 左X 種別 / 左Y 最初から / 左スティックで目線の高さ。トリガーでレバーをつかみ、手前に引くと力行、奥へ押すとブレーキ(両手どちらでも可)

速度段階・加減速度は実車を参考にした簡易モデルです。停止許容は ±3 m(やさしい)から ±0.5 m まで選べ、速度パネルに「ブレーキ目安」が出ます。駅間距離は東急電鉄の公開データ、二子新地・高津は大井町線の駅間表に無いため省略しています。車内放送の音声: Open JTalk + 「Mei」(MMDAgent Example, CC BY 3.0 / 名工大)。
